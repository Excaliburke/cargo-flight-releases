# Cargo Flight

Downloads and update manifests for Cargo Flight, a Mac app that carries Google Drive folders down to disk, sorts them for a migration, and lets Claude work on Drive files.

To install, open [the latest release](https://github.com/Excaliburke/cargo-flight-releases/releases/latest), download `Cargo-Flight-X.Y.Z.dmg`, open it, and drag Cargo Flight onto Applications.

The `.zip` and `latest-mac-arm64.json` on each release are read by the app's **Check for updates**. This repository holds nothing else.
